# One Word for the Boss

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735)

One word that describes the boss — an entry for the make.fun bounty
**One Word for the Boss** (`u-swift-badger-44-one-word-for-the-boss-6b48c735`).

`main.ts` scores a shortlist of candidate words against the judge's criteria
(realness, standalone humour, truth, freshness, cross-industry) and writes the
winning word — exactly one word, no spaces, no explanation — to
`/output/entry.txt`.

## Run

```bash
node main.ts
cat /output/entry.txt
```

Requires Node.js 22+.
